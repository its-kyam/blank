# Support

Need help with Blank?

## Questions and Discussions

Use GitHub Discussions for general questions, usage help, and ideas.

## Bug Reports

Use GitHub Issues to report reproducible bugs.

Please include enough information for maintainers to understand and reproduce the problem.

## Feature Requests

Feature requests should explain the problem being solved and how the proposed feature fits Blank's goals.

## Security Issues

Do not report security vulnerabilities through public issues. Follow the instructions in [SECURITY.md](SECURITY.md).
