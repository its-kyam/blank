# Code of Conduct

## Our Standards

Blank is an open-source project built around simplicity, performance, and collaboration.

Everyone participating in the project is expected to:

- Be respectful and considerate.
- Welcome constructive criticism and differing opinions.
- Keep discussions focused and productive.
- Give feedback without personal attacks or harassment.
- Respect the time and contributions of other participants.

## Unacceptable Behaviour

The following behaviour is not acceptable:

- Harassment, discrimination, or personal attacks.
- Threats, intimidation, or deliberate hostility.
- Publishing someone's private information without permission.
- Trolling, spam, or intentionally disruptive behaviour.
- Any other conduct that creates an unsafe or hostile environment.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards.

Maintainers may remove comments, reject contributions, restrict participation, or take other appropriate action when this Code of Conduct is violated.

## Reporting

Report violations privately to the project maintainers through the project's official communication channels.

All reports will be reviewed as fairly and confidentially as possible.

## Scope

This Code of Conduct applies to all project spaces, including repositories, issues, pull requests, discussions, and other community spaces associated with Blank.
